# fma-industries

Simple marketing and work-request management site for FMA Industries.

## Run locally

From the repository root:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Features

- HVAC services marketing content
- Work-request submission form
- In-browser request management (status updates and delete)
- Data persisted in browser local storage
